개인정보처리방침 (하이볼 / High Ball)

최종 수정일: 2026-10-05

본 방침은 HyperCasting(이하 "개발자")이 모바일 게임 "하이볼(High Ball)"(패키지명 com.hypercasting.highlowball, 이하 "앱")을 통해 어떤 정보를 수집·이용·보관하는지 설명합니다.

1. 수집하는 정보

앱은 이름, 이메일, 전화번호, 위치, 연락처, 카메라, 마이크를 요구하지 않습니다. 앱을 실행하면 백엔드 서비스(Supabase)를 통해 익명 로그인이 이루어지고, 기기마다 무작위 사용자 ID가 발급됩니다. 그 ID 아래에 다음 정보를 저장합니다.

항목목적다른 플레이어에게 보이는지
익명 사용자 ID(무작위, 신원과 연결되지 않음)기록을 다른 플레이어와 구분닉네임이 없을 때 축약 형태로 표시될 수 있음

기기에만 저장되는 정보: 설정(소리, 진동, 언어, 색), 스테이지 목록 캐시, 다음 실행에도 같은 익명 계정을 쓰기 위한 로그인 세션, 광고 동의 선택(Google UMP가 저장).

푸시 알림 토큰: 앱이 꺼져 있을 때 "누가 내 기록을 앞질렀어요", "시즌 엘리트 달성", 순위 변동 같은 게임 알림을 보내기 위해 Google Firebase Cloud Messaging(FCM)이 발급한 기기 토큰과 알림 언어(한국어/영어)를 익명 사용자 ID에 연결해 저장합니다. 알림 권한을 허용하지 않으면 알림이 표시되지 않으며, 기기 설정에서 언제든 끌 수 있습니다. 토큰은 알림 전송에만 쓰이고 앱을 지우면 더 이상 쓰이지 않습니다. Google이 FCM 정보를 어떻게 쓰는지: https://firebase.google.com/support/privacy

앱은 분석 기능을 쓰지 않습니다. Firebase SDK에 포함된 Google Analytics 수집은 꺼 두었고, Unity Analytics와 충돌 보고 기능도 꺼져 있습니다.

1-1. 광고 (Google AdMob)

앱은 무료이며 Google AdMob 광고를 보여줍니다. 현재는 이용자가 직접 누를 때만 재생되는 보상형 광고 (시청하면 하트 1개)가 있습니다. 광고를 보여주고 측정하기 위해 Google AdMob SDK가 기기에서 다음 정보를 수집해 Google에 보냅니다.

  • 광고 ID(Android 광고 ID)와 앱 세트 ID
  • 기기 정보(기기 모델, OS 버전, 언어, 화면 크기 등)와 앱 정보
  • IP 주소(이로부터 추정한 대략적인 위치 — 정확한 위치는 수집하지 않습니다)
  • 광고 노출·클릭 등 광고와의 상호작용, 진단 정보

이 정보는 광고 제공, 광고 성과 측정, 부정 방지, 그리고 동의한 경우 맞춤 광고에 쓰입니다. 개발자는 광고 ID를 직접 저장하거나 게임 계정과 연결하지 않습니다. Google이 정보를 어떻게 쓰는지: https://policies.google.com/technologies/partner-sites, Google 개인정보처리방침: https://policies.google.com/privacy

맞춤 광고 동의와 철회: 유럽경제지역(EEA)·영국·스위스 등 동의가 필요한 지역에서는 첫 실행 때 Google의 동의 화면(UMP)이 뜨고, 이후 언제든 앱의 설정 → 개인정보 → 개인정보 옵션에서 선택을 바꾸거나 철회할 수 있습니다. 모든 지역에서 기기 설정(설정 → Google → 광고 → 광고 ID 삭제 또는 맞춤 광고 해제)으로 광고 ID 사용을 제한할 수 있습니다. 앱은 13세 이상 이용자를 대상으로 하며 아동 대상 광고 설정을 사용하지 않습니다.

2. 저장과 처리

데이터는 암호화된 연결(HTTPS/WSS)로 전송되어 백엔드 서비스 Supabase(Amazon Web Services 인프라)에 저장됩니다. https://supabase.com/privacy 참고.

3. 정보 공유

닉네임, 기록, 순위는 공개 랭킹에 표시됩니다. 리플레이는 순위가 비슷한 다른 플레이어가 볼 수 있으며, 각 스테이지 상위 10명의 리플레이는 서버가 비공개로 유지합니다. 광고 표시를 위해 Google AdMob SDK가 1-1항의 정보를 Google에 직접 보냅니다. 그 밖에 개발자는 여기 적힌 게임 운영 목적 외에 어떤 목적으로도 게임 데이터를 판매·대여·제3자 제공하지 않습니다.

4. 보관 기간

게임 데이터는 계정이 존재하는 동안 보관됩니다. 앱을 삭제해도 서버 데이터는 자동으로 지워지지 않으니 아래 방법으로 삭제해 주세요.

5. 데이터 삭제

앱에서: 설정 → 개인정보 → 내 데이터 삭제를 누르고 한 번 더 눌러 확인하세요. 계정과 서버의 모든 데이터(기록, 순위, 리플레이, 닉네임, 하트, 알림, 멀티플레이 기록)가 즉시 영구 삭제되고, 기기의 앱 데이터도 지워진 뒤 앱이 종료됩니다. 다음 실행 때는 새 빈 계정으로 시작합니다.
