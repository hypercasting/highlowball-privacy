개인정보처리방침 (하이볼 / High Ball)

최종 수정일: 2026-09-29

본 방침은 HyperCasting(이하 "개발자")이 모바일 게임 "하이볼(High Ball)"(패키지명 com.hypercasting.highlowball, 이하 "앱")을 통해 어떤 정보를 수집·이용·보관하는지 설명합니다.

1. 수집하는 정보

앱은 이름, 이메일, 전화번호, 위치, 연락처, 카메라, 마이크를 요구하지 않습니다. 앱을 실행하면 백엔드 서비스(Supabase)를 통해 익명 로그인이 이루어지고, 기기마다 무작위 사용자 ID가 발급됩니다. 그 ID 아래에 다음 정보를 저장합니다.

항목목적다른 플레이어에게 보이는지
익명 사용자 ID(무작위, 신원과 연결되지 않음)기록을 다른 플레이어와 구분닉네임이 없을 때 축약 형태로 표시될 수 있음

리플레이 데이터: 그린 선과 공의 궤적리플레이, 랭킹, 부정 기록 확인일부(3항 참고)

기기에만 저장되는 정보: 설정(소리, 진동, 언어, 색), 스테이지 목록 캐시, 다음 실행에도 같은 익명 계정을 쓰기 위한 로그인 세션.

앱에는 광고 SDK와 분석 SDK가 없으며, Unity Analytics와 충돌 보고 기능도 꺼져 있습니다. 현재 버전은 푸시 알림 토큰을 수집하지 않습니다.

2. 저장과 처리

데이터는 암호화된 연결(HTTPS/WSS)로 전송되어 백엔드 서비스 Supabase(Amazon Web Services 인프라)에 저장됩니다. https://supabase.com/privacy 참고.

3. 정보 공유

닉네임, 기록, 순위는 공개 랭킹에 표시됩니다. 리플레이는 순위가 비슷한 다른 플레이어가 볼 수 있으며, 각 스테이지 상위 10명의 리플레이는 서버가 비공개로 유지합니다. 개발자는 여기 적힌 게임 운영 목적 외에 광고 등 어떤 목적으로도 정보를 판매·대여·제3자 제공하지 않습니다.

4. 보관 기간

게임 데이터는 계정이 존재하는 동안 보관됩니다. 앱을 삭제해도 서버 데이터는 자동으로 지워지지 않으니 아래 방법으로 삭제해 주세요.

5. 데이터 삭제

앱에서: 설정 → 개인정보 → 내 데이터 삭제를 누르고 한 번 더 눌러 확인하세요. 계정과 서버의 모든 데이터(기록, 순위, 리플레이, 닉네임, 하트, 알림, 멀티플레이 기록)가 즉시 영구 삭제되고, 기기의 앱 데이터도 지워진 뒤 앱이 종료됩니다. 다음 실행 때는 새 빈 계정으로 시작합니다.

이메일로: 앱이 설치되어 있지 않다면 joongangatech@gmail.com으로 제목 "High Ball 데이터 삭제", 닉네임과 확인에 도움이 되는 정보(기록 화면 캡처 등)를 보내 주세요. 30일 이내에 해당 계정을 삭제합니다. 자세히: delete-account.html

6. 아동의 개인정보

앱은 아동의 개인정보를 의도적으로 수집하지 않습니다. 실명이나 연락처를 요구하지 않으며, 자유 입력은 몇 글자짜리 선택 닉네임뿐입니다. 아동이 닉네임에 개인정보를 입력했다고 생각되면 연락 주시면 삭제합니다.
